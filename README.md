# בעיטת אצבע ⚽ – Flick Kick

משחק פנדלים נייטיב לאנדרואיד (Kotlin) ל-Galaxy S25+.
הבעיטה מתבצעת ב"פליק" אצבע מול המצלמה הקדמית: מצמידים את האצבע המורה לאגודל ומשחררים בתנופה.

## איך משחקים
1. מעמידים את הטלפון זקוף (על מעמד/ספל), המצלמה הקדמית מול היד, במרחק 30–50 ס"מ.
2. **כיוון** – מזיזים את כל כף היד: ימינה/שמאלה = צד השער, למעלה/למטה = גובה הבעיטה. הכוונת על השער עוקבת אחרי היד.
3. **טעינה** – מצמידים את קצה המורה לאגודל. הכוונת הופכת ירוקה ופועמת.
4. **בעיטה** – משחררים את האצבע בתנופה מהירה. מהירות השחרור = עוצמת הבעיטה.
   בעיטה חזקה מהירה יותר לשוער, אבל פחות מדויקת.
5. 10 בעיטות בסבב. כל גול מקשה על השוער. השיא נשמר.

בלי מצלמה (או באמולטור): החלקת אצבע על המסך כלפי מעלה = בעיטה.

## בנייה והתקנה
1. פותחים את התיקייה `FlickKick` ב-Android Studio (Ladybug ומעלה) ומחכים לסנכרון Gradle.
2. בבנייה הראשונה מודל זיהוי היד (`hand_landmarker.task`, כ-7.8MB) יורד אוטומטית ל-`app/src/main/assets`.
   אם אין גישה לרשת בזמן הבנייה – מורידים ידנית מ:
   https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
   ושמים בתיקייה הזו.
3. בטלפון: הגדרות ← אודות הטלפון ← פרטי תוכנה ← 7 הקשות על "מספר Build" ← אפשרויות מפתחים ← ניפוי USB.
4. מחברים בכבל ולוחצים Run ▶.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `HandTracker.kt` | מצלמה קדמית (CameraX) + MediaPipe Hand Landmarker – 21 נקודות של כף היד בכל פריים |
| `FlickDetector.kt` | מכונת מצבים שמזהה טעינה (מורה↔אגודל) ושחרור מהיר, ומחשבת עוצמה |
| `GameView.kt` | המשחק: הטלה פרספקטיבית, פיזיקת כדור, שוער AI, ציור וממשק |
| `MainActivity.kt` | הרשאת מצלמה, מסך מלא, חיבור הרכיבים |

## כיוונון (אם הזיהוי רגיש מדי / לא רגיש)
ב-`FlickDetector.kt`, בתוך `companion object`:
- `LOAD_RATIO` – כמה קרוב המורה לאגודל כדי להיחשב "טעון" (להגדיל אם קשה לטעון).
- `RELEASE_RATIO` – כמה רחוק כדי להיחשב "שוחרר".
- `MIN_SPEED` / `MAX_SPEED` – טווח המהירויות שממופה לעוצמה 0–100%.
- `MAX_RELEASE_MS` – שחרור איטי מזה לא נחשב פליק.

בכל המרחקים יחידת המידה היא "גודל כף יד" (שורש כף היד ← בסיס האצבע האמצעית), כך שהזיהוי לא תלוי במרחק מהמצלמה.
